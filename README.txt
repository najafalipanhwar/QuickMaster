QUIZMASTER - INTERACTIVE QUIZ APP
==================================
Built with HTML, CSS and JavaScript.

FEATURES
- Category selection
- Difficulty selection
- Choose number of questions
- 20-second timer per question
- 40 balanced multiple-choice questions across categories and difficulty levels
- Automatic scoring
- Correct/wrong/skipped statistics
- Answer review
- Restart quiz
- Dark/light mode
- Responsive design

RUN
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Select quiz settings and click Start Quiz.

NOTE
This is a frontend educational/demo project. Questions are stored in script.js.
